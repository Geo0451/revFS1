Widget positions

showwidgetxyoffset
Unchecking "show" doesn't erase the widget's position — it moves it off-canvas (x=250, y=300) only in the exported file, so you can re-check it later without losing where you'd placed it. Note: this hides the live number the watch draws for that widget. If a widget's icon is baked into your photo itself (not drawn by the watch), you'll need to paint over it in the photo separately.

Colours & fonts (experimental)

Load a template first.
Digits/labels are small pictures stored in the file, so colour is baked into them. Each row is one image set; widgets that share a set (e.g. Hours+Minutes) change together. Colour re-tints the set in place (file size unchanged; safest). Font re-renders the digits from a font installed on this computer and rebuilds the file tail (sizes and directory are rewritten) — untested on the watch, expect to try it a couple of times. Multi-colour sets (AM/PM, weekdays) end up single-tint.
