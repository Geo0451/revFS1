Widget positions

show widget x y offset
Unchecking "show" doesn't erase the widget's position — it moves it off-canvas (x=250, y=300) only in the exported file, so you can re-check it later without losing where you'd placed it. Note: this hides the live number the watch draws for that widget. If a widget's icon is baked into your photo itself (not drawn by the watch), you'll need to paint over it in the photo separately.

Colours & fonts (experimental)

Load a template first.
The preview shows the real glyphs at their real positions (time = now, numbers = sample). Digits/labels are pictures stored in the file, so colour, font and size are baked in. Height rescales a set (widget W/H are rewritten to match). Font re-renders digits from a font on this computer. Own set gives a widget a private copy of the images (e.g. a different Minutes colour): it appends images and grows the directory, shifting the tables behind it — the most invasive edit here, untested. Hold Shift while dragging to disable snapping.
